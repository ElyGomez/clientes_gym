# Análisis de clientes de gimnasio

## Descripción general

Este proyecto realiza un análisis exploratorio de los clientes de un gimnasio con el objetivo de
comprender patrones de uso, cancelaciones y duración de contratos. El análisis busca responder
preguntas clave sobre el comportamiento de los clientes con datos reales, lo cual permite
tomar decisiones informadas para mejorar la retención y optimizar estrategias de servicio.

El enfoque principal es analizar la **frecuencia de asistencia, cancelaciones, duración de
contratos y comportamiento de los miembros**, ayudando a identificar segmentos de clientes
y posibles áreas de mejora en la gestión del gimnasio.

---

## Preguntas de negocio

- ¿Qué patrones de asistencia tienen los clientes?
- ¿Cómo se relaciona la duración del contrato con la frecuencia de visitas?
- ¿Existen grupos de clientes con características similares?
- ¿Qué variables parecen influir en las cancelaciones?

---

## Herramientas utilizadas

- Python  
- Pandas y NumPy  
- Visualización de datos con Matplotlib y Seaborn  
- Análisis exploratorio de datos  
- Jupyter Notebook  

---

## Principales insights

- Los clientes con mayor frecuencia de asistencia tienden a tener contratos más largos.
- Se observa un grupo de miembros con alta probabilidad de cancelación.
- El análisis de segmentos muestra patrones distintos según frecuencia de uso.
